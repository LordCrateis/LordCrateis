### ⚡ Technical Focus

I prioritize performance and scalability — systems lean enough to run serverless and fast enough to handle high-velocity data.

- **Performance Engineering** — deep in **Polars** for memory-efficient, vectorized data processing; building pipelines that outperform traditional Pandas-based workflows.
- **Machine Learning** — specialized interest in **Few-Shot Learning** and **Anomaly Detection**, extracting signal where data is scarce or irregular.
- **Scalable Infrastructure** — architecting serverless solutions on **AWS Lambda** and **Azure Functions** that scale without the overhead.
